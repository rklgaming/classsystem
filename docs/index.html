✦How do I…?

Everything you can do, step by step - pick a task, or type a few words in the search bar above.
Admin tasks only work for admins: the server checks every request, so players can never change spells, classes or levels.

1The classes

Twenty classes, each with its own mana, passive, ten spells, ten ranks and a hall. Pick one.

2Controls

Click a key to see what it does. Every key is rebindable in Settings › Key Bindings › FiveM (search the class name).

Hold Right mouse and press 1-0 to cast.

3Levels & spell ranks

Each class has its own level, 1 to 50. Every level gives a skill point; points rank up spells in the hall's Skills tab.

Each rank: +6 % power, -4 % cooldown, -3 % cost (defaults; a spell may set its own). PvP caps still apply.

4The class hall

/manageclass opens the hall of your class. What you see depends on your rank - the server decides.
