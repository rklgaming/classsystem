1The classes

Eleven classes, each with its own mana, passive, ten spells, ten ranks and a hall. Pick one.

2Controls

Click a key to see what it does. Every key is rebindable in Settings › Key Bindings › FiveM (search the class name).

Hold Right mouse and press 1-0 to cast.

3Levels & spell ranks

Each class has its own level, 1 to 50. Every level gives a skill point; points rank up spells in the hall's Skills tab.
